# Shared contract

Modify the supplied correct v0 starter into v1. Preserve all explicitly preserved behavior and the fixed ABI. Use only your supplied representation. Return complete raw source without Markdown fences, explanations, tests, new handlers, or changes to field/event declarations. One generation, no feedback, tools, repair, retries, or persistent conversation. Output limit 4096 tokens; source limit 16384 UTF-8 bytes. Input estimate ceiling 24000 UTF-8 bytes + 256/message is NOT a verified input-token ceiling. No padding or omitted necessary requirements.

EntityID is a four-element value [world_epoch,tick,job,ordinal]. Equality means all four components equal. Entities have no separate role type. Roles may alias unless a task explicitly specifies an alias no-op. Exists/resolve tests existence, not presence of fields. Required read of a missing cell throws InvalidEntity; do not replace missing cells with zero/false. bool is strict; integers are checked safe integers, and stored fields obey ABI ranges. Input payloads are trusted closed records; task-specific integer domains are public requirements. No out-of-domain inputs are part of this contract.

One Open handler id=open, priority=0; JS exports only synchronous onOpen returning undefined. Tick has no handler. services/extensions remain empty. Fields have authority IR, policy exclusive. Pure locals, conditions, short circuit, comparisons, and checked sub are available. Addition uses checked sub(a,sub(0,b)); both representations receive this fact. Only resolve/exists, read/require, checked sub, write and emit are needed. No imports, files, network, services, clock, random, dynamic code, timers, global mutable state, or additional host capabilities.

Each input event sees previous input events committed in this tick. A fault rolls back the entire current tick, including prior input effects and published events; earlier completed ticks remain committed. Normal business rejection commits. Output events are delivered in emission order. All unmentioned fields remain unchanged; no unmentioned events; commands=[].

Resource limits: 128 host operations/tick, 32 JS wire requests/handler including done, 256 wire requests/tick, 8192-byte IPC request/response line; bootstrap limit 32768 bytes; max 10 seconds per invocation, 64MiB, 0.25 CPU, 32 PID in the existing isolated runtime. AST work and JS compute are different measures. Evaluation observes complete entities and per-tick status/error/business events/commands plus deterministic replay. Internal harmless read ordering is not an equality requirement. Follow the specified short circuit priorities and calculate required values before business effects.

Independent syntax example ONLY: Probe Open:{target:EntityID}, field probe:int[0,10]/IR/exclusive. Its entire behavior is writing probe=7. The task ABI and behavior below replace this example; the example is not another required handler.
